# Food Menu - C++ Program

A simple console-based food ordering menu made in C++.

### Menu Items:
1. Burger - $5
2. Pizza - $8
3. Sandwich - $4

### Features:
- User apni choice select karta hai
- Quantity enter karta hai
- Program total bill calculate karke show karta hai
- Agar galat choice ho to "item not available" show hota hai

### How to Run:
1. Dev C++ me Menu.cpp open karo
2. Compile & Run karo
3. Choice (1,2,3) aur Quantity enter karo

### Language Used:
C++
